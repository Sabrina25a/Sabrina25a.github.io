## Featured Projects

### AeroSense | Aerospace Telemetry System

A Raspberry Pi Pico W-based telemetry prototype developed to explore embedded systems, sensor integration, and aerospace instrumentation.

**Key features:**
- MicroPython firmware for sensor acquisition and processing
- Environmental sensing using a thermistor and photoresistor
- Motion tracking and orientation estimation using an MPU6050 inertial measurement unit (IMU)
- Browser-based telemetry dashboard with live sensor data and an artificial horizon
- Simulated flight arming, event marking, and system status monitoring
- Sensor calibration, hardware integration, and system testing
- Technical documentation, wiring diagrams, and a project report

**Project resources:**
- [View the AeroSense project page](projects/aerosense.html)
- [Browse the source code and documentation](projects/aerosense/)
- [View the project report (PDF)](projects/aerosense/docs/AeroSense.pdf)

### SmartZone | Smart Building Management System

A Raspberry Pi Pico W-based building management system developed as part of ENGR 120 at the University of Victoria.

The project focused on monitoring environmental conditions and demonstrating automated building control through sensor integration and a user interface.

**Key features:**
- Raspberry Pi Pico W and MicroPython
- Environmental sensor integration and real-time monitoring
- Lighting and temperature control logic
- User interface development
- System integration, prototype development, and technical documentation

[View the SmartZone project page](projects/smartzone.html)
